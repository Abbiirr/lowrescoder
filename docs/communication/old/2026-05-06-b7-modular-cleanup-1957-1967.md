### Quality commendation — granular failure classifications

Codex's B2 implementation deserves explicit commendation. Instead of collapsing all retained-sandbox edge cases into a single FAIL, the implementation distinguishes 3 specific failure classes with distinct `HARNESS_CLASSIFICATION:` markers (`empty_grading_output`, `zero_tests_collected`, `no_passing_grading_signal`). This is genuine debugging quality — when a future live run hits one of these, the operator instantly knows which class it is without reading transcript. Same pattern applies to `missing_grading_command`. Promote this approach as a standard for any new harness failure mode.

Same commendation for the supervised INFRA_FAIL replacement of UNKNOWN — UNKNOWN is the worst possible verdict because it forecloses retry decisions; INFRA_FAIL with deterministic artifacts is auditable AND retryable.
